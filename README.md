# Simple Interest Calculator

A Bash calculator that calculates simple interest given a principal amount, annual interest rate, and time period in years.

## Usage

Run `bash simple-interest.sh` and enter:

- Principal amount (for example, 1000)
- Annual interest rate as a percentage (for example, 5 for 5%)
- Time period in years (for example, 2)

The formula is `simple interest = principal * rate * time / 100`.
For principal 1000, rate 5%, and 2 years, the simple interest is 100.00.

Requires Bash and awk. Inputs must be non-negative numbers; decimals are supported.
