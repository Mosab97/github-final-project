# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

1. Open an issue to discuss a bug or proposed improvement.
2. Fork this repository and create a branch for your change.
3. Make focused changes and update relevant documentation.
4. Check syntax with `bash -n simple-interest.sh` and run the calculator with representative inputs.
5. Open a pull request describing the change and how you checked it.

Follow our [Code of Conduct](CODE_OF_CONDUCT.md). By submitting a contribution, you agree that your contribution is licensed under the Apache License 2.0.
